# Molecules

Compositions of atoms — and, where unavoidable, raw text/image layers
the team has accepted into the system. A molecule references its atoms
by instance and never duplicates their bindings.

One folder per molecule. Token discipline: the molecule's own bindings
(spacing, layout, any non-atom text) reference `Semantic: *` only.

Live molecule in this demo: `Jumbotron` (Jumbotron page).
