# Atoms

Smallest functional UI units. Each atom is a single Figma component or
component set whose every fill, stroke, font, dimension, and spacing
binds to a `Semantic: *` variable. Atoms never reference primitives
directly and never compose other components.

One folder per atom, named after the component (`button/`, `artwork/`,
`status-bar/`). Folder contents are added per the component's
downstream documentation pipeline.

Live atoms in this demo: `Button` (Button page), `Artwork` (Artwork
page), `Status Bar` (Utility page).
