# Patterns

Composition blueprints — **Markdown only**. No `tokens.json`, no Figma
component, no preview asset. A pattern documents how to assemble
existing atoms / molecules / organisms into a recurring layout (sign-up
flow, empty state, full-bleed hero with CTA), but the layout itself is
recreated each time it's used rather than living as a published
component.

If a pattern starts being reused with the same overrides repeatedly,
promote it to a molecule or organism.
